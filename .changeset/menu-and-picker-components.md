Add Combobox, Command, Context Menu, Dropdown Menu, Menubar, Navigation Menu and Select. Menus share `lib/menu.ts` for focus, keyboard and submenu behavior; command menus and comboboxes keep focus in their input and track the active option with `aria-activedescendant`. Floating content can be anchored to a point.
