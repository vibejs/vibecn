# 0004. Optional VibeDND compositions

Status: Proposed

The dnd source compositions use the public @usevibejs/dnd adapter. They declare the dependency in the selected registry entries, leaving all other installations unchanged. Application arrays own rendered order. Lists create a context; item and drop-zone parts consume the nearest context. Kanban transfers are immutable final-drop commits. No component nodes are imperatively moved by registry code. Native buttons remain the drag handles. The existing Card, Badge and Empty components supply styling.
